# uLarn for GFOS

The AmiCradle Team's port of uLarn (Phil Cordier's roguelike after Noah
Morgan's Larn) to GFOS: AmigaOS 3.2 with GFOpenUp, 68040/68060, in its own
80 x 24 console window. It ships as a release archive with an Installer and
as the GFOpenUp part Parts/uLarn.

Upstream is fetched at build time (package/ularn.lock) and patched
(amiga/patches); this repository holds only the Amiga port. See
[AMIGA_PORT.md](AMIGA_PORT.md).
